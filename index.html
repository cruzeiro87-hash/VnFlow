먼저 설정에서 무료 AI 서비스 키를 입력해 주세요. 1~2분이면 받을 수 있어요.

AI 연결 (무료)

    ‘연결 확인’을 누르면 쓸 수 있는 모델 목록을 불러와요.

    디자인 스타일

    고른 스타일은 이 기기에 저장돼요. 고대비 스타일은 글자와 경계선을 가장 또렷하게 보여줘요.

    병렬 텍스트는 원문과 번역을 좌우로, 대화형은 말풍선으로 보여줘요.

    번역 기록

    기록은 이 기기에만 저장되고 GitHub로 동기화되지 않아요. 업무 메일 내용이 남기 때문에 공용 기기에서는 꺼 두세요. 저장한 단어는 이 설정과 상관없이 단어장에 남아요.

    발음

    원문 언어에 맞는 음성을 자동으로 골라요. 기기에 설치된 음성 중 가장 자연스러운 것을 써요.

    단어장 자동 연동 (GitHub)

    GitHub 계정의 비공개 Gist에 단어장을 저장해서, 폰과 PC가 같은 단어장을 써요. 기기마다 한 번씩 토큰을 넣어 주세요.

    1. 새 토큰 만들기 화면을 열고 이름을 적어요.
    2. 권한(Permissions)에서 Gists를 찾아 Read and write로 정해요. GitHub Models도 같이 쓰려면 Models를 Read-only로 함께 추가하세요.
    3. 토큰을 생성해 복사한 뒤 아래에 붙여넣고 ‘연동 시작’을 눌러요.
    Gist는 ‘비공개 링크’ 방식이라 검색이나 목록에는 나오지 않지만, 주소를 아는 사람은 볼 수 있어요. 단어와 예문만 저장돼요.

    단어장 파일로 옮기기

    폰과 PC의 단어장을 맞추려면 한쪽에서 내보낸 파일을 다른 쪽에서 가져오세요. 같은 단어는 더 최근에 수정한 쪽이 남아요.
